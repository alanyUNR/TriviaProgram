# Possible New Features for `triviaProgram`

## 1. Difficulty and Question-Count Selection
Allow players to choose an easy, medium, or hard quiz and specify how many questions to answer. Difficulty could be determined through Markdown metadata or separate question files.

## 2. Score History and High Scores (Current Feature Improvement)
Create a .md called (scoreTracker.md) which describes the code updates needed to save each player’s score, quiz name, accuracy percentage, and date to a .CSV file based on the program in the triviaProgram folder. 

## 3. Timed Quiz Mode
Add an optional timer for each question or for the entire quiz. Faster correct answers could earn bonus points, while timed-out questions would automatically count as incorrect.
